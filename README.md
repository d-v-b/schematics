# schematics

## About

This repository contains models / plans for physical things. Likely stuff I need to 3D print at home.

## Schematics

- [`curtain-hanger/`](curtain-hanger/): hang IKEA FRAMFUSIG curtain rails from a ceiling beam.
- [`bolt-bar/`](bolt-bar/): a 40 x 5 mm bar with slots for M6 bolts that sits on a 40 mm aluminium rail.
- [`spacer/`](spacer/): a star-shaped band that spaces an acrylic sheet off the rafter it is screwed to.
